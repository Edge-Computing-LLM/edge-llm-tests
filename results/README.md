# Validation results

Each dated directory contains sanitized, point-in-time evidence generated by
`edge-llm-tests`. A report is not a permanent health claim. Compare its UTC
timestamp, source commits, branches, and live environment before relying on it.

Committed evidence may contain tool output and cluster object names, but must
not contain credentials, Kubernetes Secret data, kubeconfig content, private IP
addresses, pod logs, prompts, responses, or model weights.
